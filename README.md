# ASN-IP-CN
ASN and IP List in China (Auto Update)(with other tools)

[简体中文](./README.zh_CN.md)

## Features
- Automatic daily updates(by github workflow)
- Reliable and accurate source
- More config...

## Data Source
### ASN Information
- [bgp.he.net](https://bgp.he.net/country/CN)
- [whois.ipip.net](https://whois.ipip.net/countries/CN)

### IP Information
- [cbuijs/ipasn](https://github.com/cbuijs/ipasn)
- [ipverse/asn-ip](https://github.com/ipverse/asn-ip)

## scripts
- base python3
- require `pip install requests lxml`
- run in current folder`python main.py`
